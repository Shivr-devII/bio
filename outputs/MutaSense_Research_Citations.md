# MutaSense — Professional Cases and Citations

Research snapshot: 6 October 2026. The records below were retrieved through the actual ClinVar and Europe PMC APIs. This file is a dated classroom research snapshot, not a continuously updated clinical review. Paper titles, authors, years, identifiers and source links are taken from the API response. Abstract excerpts and metadata were retrieved; full-text analysis was not performed.

## Database choices

| Source | What MutaSense retrieves | Interpretation boundary |
| --- | --- | --- |
| NCBI ClinVar | Variant identity, versioned accession, germline classification and review status | The classification belongs to the record and its contexts; it does not diagnose the input fragment or a person. |
| Europe PMC | PubMed-indexed paper metadata and abstract excerpts | Related literature is background evidence; paper type and population matter. |
| PubMed / PMC | Direct bibliographic and available full-text links | Full papers must be read before making detailed study claims. |
| GeneReviews / MedlinePlus Genetics | Curated teaching sources used for the known HBB case | Teaching references are marked separately from live API retrieval. |

## Evidence standard

A source ID links a claim to a source that the model received; it does not prove that the model interpreted that source correctly. A gene-only search is not a match to an input fragment. Known professional cases below are examples for comparing sequence consequences. Only the exact curated HBB input pair, selected frame and context receive a matched-case explanation. A reader should check the record version, review status, experimental design and relevance.

## HBB — Sickle-cell variant

**Sequence class:** Missense substitution.

The classroom HBB example changes coding GAG to GTG and glutamate to valine. The full-transcript identity is c.20A>T, HGVS p.Glu7Val; traditional mature beta-globin numbering uses Glu6Val. The matched case is used to teach the difference between an amino-acid consequence and a clinical diagnosis. [ClinVar source record](https://www.ncbi.nlm.nih.gov/clinvar/variation/15333/).

**Database identity:** NM_000518.5(HBB):c.20A>T (p.Glu7Val). Accession VCV000015333.183.

## CFTR — p.Phe508del

**Sequence class:** In-frame deletion.

The selected ClinVar record identifies CFTR c.1521_1523del and p.Phe508del. It is a useful professional contrast to a one-base frameshift: three coding bases are deleted and the downstream reading frame is preserved. A preserved frame does not establish normal protein function. This is a research-library case, not a DNA input preset or an automatic match. [ClinVar source record](https://www.ncbi.nlm.nih.gov/clinvar/variation/7105/).

**Database identity:** NM_000492.3(CFTR):c.1521_1523del (p.Phe508del). Accession VCV000007105.213.

## BRCA1 — c.68_69del

**Sequence class:** Frameshift deletion.

The selected ClinVar record identifies BRCA1 c.68_69del and p.Glu23fs. It illustrates why deleting two coding bases can shift downstream codons. A source record and a protein consequence do not by themselves provide an individual risk estimate. This is a research-library case, not a DNA input preset or an automatic match. [ClinVar source record](https://www.ncbi.nlm.nih.gov/clinvar/variation/17662/).

**Database identity:** NM_007294.4(BRCA1):c.68_69del (p.Glu23fs). Accession VCV000017662.188.
